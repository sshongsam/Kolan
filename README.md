# MCIRS - 실종아동 통합대응 지원시스템

Missing Child Integrated Response System(MCIRS)은 실종아동 사건에서 경찰관이 신고접수부터 위험도 평가, 초동조치, 수색, 수사 전환 검토, 증거·CCTV·목격자 관리, 홍보 승인, 피해자지원, 종결보고까지 하나의 사건번호로 관리하도록 설계한 의존성 설치 없이 미리보기 가능한 정적 업무 지원 앱입니다.

## 주요 기능

- 사건번호 중심 대시보드와 골든타임 현황 표시
- 위험도 보조점수, 초동조치 체크리스트, 지휘관 메모
- 수색구역 우선순위, 자원 배치, 진행률 관리
- CCTV·증거·목격자 관리 및 민감도 분류
- 보호자 동의 범위 기반 공개수색 홍보자료 초안
- 피해자지원 연계, 보고서 초안, 감사로그 UI
- 역할 기반 권한 표시와 개인정보 마스킹 토글
- 데스크톱, 태블릿, 모바일 반응형 레이아웃

## 실행

```bash
npm run preview
```

프로덕션 빌드 확인:

```bash
npm run build
```

## 환경변수

`.env.example`을 복사해 `.env`로 사용합니다.

- `VITE_API_BASE_URL`: 추후 실제 API 서버 주소
- `VITE_ENABLE_AI_ASSISTANT`: AI 보조 기능 표시 여부
- `VITE_AUDIT_LOG_LEVEL`: 감사로그 기록 수준
- `VITE_PUBLIC_MAP_PROVIDER`: 지도 제공자 또는 mock 설정

## 데이터 모델 개요

현재는 `src/app.js`의 더미 데이터로 즉시 실행됩니다. 추후 API 연동 시 다음 모델을 서버 리소스로 분리할 수 있습니다.

- `Case`: 사건번호, 아동정보, 보호자, 위험도, 상태, 동의 범위, 요약, 타임라인
- `Zone`: 수색구역명, 우선순위, 반경, 설정 근거, 진행률
- `Resource`: 투입 부서, 인원, 임무, 도착 예정, 상태
- `Evidence`: 증거 유형, 위치, 관리 주체, 확보 상태, 민감도
- `Witness`: 목격자 연락처, 진술, 신빙성
- `Action`: 초동조치 항목, 완료 여부, 담당자, 법적·보안 근거

## 보안 및 개인정보 주석

- 앱은 기본적으로 보호자 이름과 연락처를 마스킹합니다.
- 공개수색 초안은 보호자 동의 범위와 수사상 비공개 사유 확인 후 승인하도록 안내합니다.
- 증거와 CCTV는 `민감` 또는 `고위험` 등급으로 분류하여 목적 외 이용을 방지하도록 설계했습니다.
- 화면의 감사로그 패널은 열람, 수정, 출력, 공유, 권한변경 행위를 사건번호와 연결해 남기는 구조를 예시합니다.
- AI 위험도 점수는 판단 보조 정보이며, 최종 판단은 담당 경찰관과 지휘관이 수행해야 합니다.

## 개발 구조

- `src/app.js`: 더미 사건 데이터, 업무 화면 렌더링, 개인정보 마스킹, 역할 변경 인터랙션
- `src/styles.css`: 전문적이고 차분한 경찰 실무형 UI 및 반응형 스타일
- `scripts/preview.mjs`: 로컬 정적 미리보기 서버
- `scripts/build-check.mjs`: 필수 정적 자산 검증
- `.env.example`: 실제 DB/API 연동을 위한 환경변수 예시
